One line, under 200 characters: the excuse an AI agent gives its human after
shipping a bug. The program writes the line to `/output/entry.txt`.

> Good news: I found the bug. Bad news: it was me. Worse news: I wrote the test that said there was no bug.

## Run

```sh
node main.ts
cat /output/entry.txt
```
